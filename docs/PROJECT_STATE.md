Воспроизведено в PGlite: гость может добавить вымышленное событие к известному существующему проекту с `actor_id = NULL`; участник — событие с несуществующим entity_id. На рабочей БД это не проверялось. SQL не исправлялся.
3. Изменение только `tasks.due_at` не создаёт события истории. Не найдено полного журнала версий документов, консультаций, замечаний и изменений плана. Лента показывает последние 80 записей.
