## Приоритетные выводы

1. Подготовка российского размещения — ближайшее отдельное направление ER-006. Смена только Next.js-хостинга не переносит Auth, PostgreSQL и файлы. Есть [инвентаризация](INFRA_INVENTORY.md), но провайдер и смета ещё не выбраны.
2. **История пока не является доверенной основой ER-005.** В локальной схеме `append_project_activity_internal` доступна `anon` и `authenticated`. Воспроизведено в PGlite: гость может добавить вымышленное событие к известному существующему проекту с `actor_id = NULL`; участник — событие с несуществующим entity_id. На рабочей БД это не проверялось. SQL не исправлялся.
3. Изменение только `tasks.due_at` не создаёт события истории. Не найдено полного журнала версий документов, консультаций, замечаний и изменений плана. Лента показывает последние 80 записей.
4. **ER-005 не реализован:** нет версионированной методики, расчётов, графического отчёта, PDF/CSV и назначений научных руководителей. Есть источники данных и базовые права проекта.
5. **ER-011 не реализован:** нет YandexGPT-адаптера, серверной генерации/черновиков, подтверждения плана, платной подписки и денежного бюджета. Квоты портфолио и рекомендаций имеют другое назначение.
6. `TimezoneSelect` уже сохраняет неизвестные старые значения и содержит российские/зарубежные IANA-зоны. В каталоге проектов остаются текстовый ввод и сравнение подстрок; расписания не реализованы.
