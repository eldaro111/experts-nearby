# Инструкции, FAQ и стартапы

Основа: main f240286. Исправление восстановления пароля сохранено.

## Что добавлено
- /help: инструкции для студентов, экспертов, заказчиков и команд стартапов.
- /help/faq: поиск по 18 вопросам, ответы раскрываются по нажатию.
- /startups: публичные незавершённые стартапы, поиск по названию, описанию, ролям и навыкам; фильтры стадии, условий, вуза/школы/группы; страницы по 24 записи.
- Создание: /listings/new?kind=startup. Стадия и условия участия сохраняются в базе.
- Редактирование существующего проекта позволяет преобразовать его в стартап или обратно; карточка показывает стадию и условия.
- Отклики, приглашения, задачи и рабочая зона используют существующий проект. Университетские проекты могут одновременно быть стартапами.
- Ссылки в шапке и подвале, адаптивная навигация.

## Порядок установки
1. До публикации кода откройте основной Supabase Experts-nearby (xvhntjcsolctjnzwuqjh), SQL Editor.
2. Выполните содержимое supabase/migrations/20261019160000_startup_projects.sql ОДИН РАЗ. В SQL Editor вставляется SQL, не команда PowerShell. Миграция только добавляет столбцы, ограничение, индекс и функцию поиска, существующие строки не удаляет. Старый сайт совместим с ней.
3. После успешной миграции загрузите код в GitHub main обычным коммитом или объединением PR. Не выполняйте слепой supabase db push: предыдущие миграции могли выполняться вручную.
4. Дождитесь Ready у Production в проекте Vercel experts-nearby-u5lr. Проверяйте новый коммит main, а не старые Preview.
5. Откройте /help, /help/faq и /startups. Создайте стартап, задайте стадию и условия, сохраните; проверьте фильтры и редактирование. Вторым аккаунтом откликнитесь и проверьте обычную рабочую зону после принятия.

Docker не нужен для выполнения этой миграции через SQL Editor и публикации кода.

## Проверки разработчика
- node scripts/tests/startups-db.mjs — ограничения полей, поиск, фильтры, исключение приватных/завершённых проектов, пагинация.
- node scripts/tests/pilot-db.mjs — новая миграция вместе с существующими, 43 проверки прежней функциональности.
- npm run typecheck; npm run build; ESLint изменённых файлов.

Инструкции описывают текущие возможности. Интеграция эскроу, автоматическая передача доли и почтовая рассылка рекомендаций не добавлены. Проверка живых откликов/файлов с двумя аккаунтами требует проверки на вашем Supabase.

## Установка из ZIP с изменёнными файлами
1. В PowerShell, находясь в вашей папке experts-nearby, выполните git status. При незакоммиченных изменениях сначала сохраните их отдельно.
2. Выполните git pull --ff-only origin main. При ошибке остановитесь.
3. Распакуйте experts-nearby-help-startups-update.zip в корень проекта, где лежит package.json, с заменой совпадающих файлов. Архив содержит только изменённые/новые файлы; он не заменяет .env.local, .git и node_modules.
4. Выполните SQL по порядку выше.
5. Выполните npm run typecheck, затем npm run build (с вашими уже настроенными локальными переменными Supabase).
6. Выполните git add src/app/help src/app/startups src/app/listings src/app/globals.css src/components/Header.tsx src/components/Footer.tsx src/components/StartupFields.tsx src/lib/helpContent.ts src/lib/startups.ts scripts/tests/pilot-db.mjs scripts/tests/startups-db.mjs supabase/migrations/20261019160000_startup_projects.sql UPDATE_HELP_STARTUPS.md
7. Выполните git commit -m "Add help FAQ and startup projects", затем git push origin HEAD:main. При любой ошибке остановитесь; force не используйте.

Сборка проверена с тестовыми значениями Supabase (без подключения к вашей базе). Проверка HTTP в локальной среде не завершена: сервер не сохранился между вызовами. Автоматическая визуальная проверка браузером не выполнена: загрузка Chromium в среде завершилась ошибкой. Мобильную навигацию и живые сценарии нужно проверить после установки.
